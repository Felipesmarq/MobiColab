# 0007 — EDA organizada em quatro princípios

- **Data:** 21/10/2026
- **Fase:** 0
- **Status:** aceita
- **Requisitos ligados:** RD04

## Contexto

A EDA precisa ser completa e avaliável, e o grupo é grande: sem uma estrutura comum, cada pessoa analisa de um jeito.

## Decisão

O notebook de EDA tem uma seção para cada princípio — **estrutural, distribucional, relacional, outliers e anomalias** — mais uma conclusão que diz o que volta para a preparação (RD02/RD03) e o que segue para o dashboard.

## Alternativas consideradas

- EDA livre, guiada só pelas hipóteses — descartada: deixa de fora checagens estruturais e de qualidade.

## Consequências

- Cada seção pode virar uma tarefa separada na fase 1.
- Cada gráfico leva um texto de interpretação logo abaixo.
